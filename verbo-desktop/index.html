Requisitos y estado de la versión

Linux de 64 bits (amd64/x86_64). El .deb requiere glibc 2.36 o posterior, por ejemplo Linux Mint 22. El .rpm está preparado para openSUSE Tumbleweed. No se garantiza compatibilidad con otras distribuciones.

Beta 0.9 (versión 0.9.0, octubre de 2026) para Linux Mint 22 o superior y openSUSE Tumbleweed / Leap 16.

Privacidad y tus recursos

La biblioteca, las notas y los ajustes se guardan en el equipo; en Linux los datos de la aplicación están en ~/.local/share/verbo-desktop. Los recursos locales pueden consultarse sin conexión. Descargar módulos, abrir enlaces o usar fuentes remotas requiere internet y comunica con sus proveedores.

El formulario de reporte de esta página abre tu cliente de correo con el texto que escribas; tú decides si lo envías. La página guarda tu elección de idioma en el navegador. Cada Biblia o módulo conserva sus propios permisos de uso.

Política de privacidad

Cómo instalar Verbo Desktop

  1. Descarga el paquete para tu sistema: .deb para Linux Mint y la familia Debian, .rpm para openSUSE.
  2. Abre el archivo descargado con doble clic e instálalo con el instalador de software de tu sistema.
Verificación avanzada (opcional)

El RPM lleva firma integrada; el DEB usa una firma .asc separada que el instalador gráfico no comprueba. Descarga la clave, la firma y el manifiesto de la misma entrega. Si el nombre, la versión o la verificación no coinciden, no instales el archivo.

Las descargas se alojan en MEGA. Antes de instalar, comprueba que el nombre del archivo y su suma SHA-256 coincidan con el manifiesto firmado.

  • verbo-desktop-public.key
  • verbo-desktop_0.9.0~dev1_amd64.deb.asc
  • SHA256SUMS
  • SHA256SUMS.asc

GPG: 736AA0E9E097E9640A371274C61F1C969BD3DAA7

Compara la huella completa de la clave antes de confiar en ella. Una firma correcta acredita el origen del paquete; no garantiza compatibilidad con tu equipo.

gpg --show-keys --with-fingerprint verbo-desktop-public.key
gpg --import verbo-desktop-public.key
gpg --output SHA256SUMS.verificado --decrypt SHA256SUMS.asc
sha256sum --ignore-missing -c SHA256SUMS.verificado

# DEB
gpg --verify verbo-desktop_0.9.0~dev1_amd64.deb.asc verbo-desktop_0.9.0~dev1_amd64.deb
sudo apt install ./verbo-desktop_0.9.0~dev1_amd64.deb

# RPM
sudo rpm --import verbo-desktop-public.key
rpm -K verbo-desktop-0.9.0~dev1-1.x86_64.rpm
sudo zypper install ./verbo-desktop-0.9.0~dev1-1.x86_64.rpm
