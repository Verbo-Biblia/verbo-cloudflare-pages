# Vacíos confirmados — capa amplia de Costumbres (Fase 3)

Este archivo documenta los huecos confirmados en las fuentes disponibles del
repositorio para la capa amplia de Costumbres por grupo+época. Son
**pendientes registrados a propósito**, no omisiones accidentales — hasta
que se sume contenido nuevo, estas combinaciones deben devolver "sin
resultado" en vez de forzar una fuente que no aplica.

Confirmado en el inventario de Paso 0 de esta fase y sin cambios desde
entonces.

## 1. Gentil / patriarcal (Mesopotamia, Canaán, Egipto — ~2091-1805 a.C.)

**Sin fuente amplia dedicada.** No existe un equivalente a Tucker para el
mundo del Cercano Oriente antiguo en la época de los patriarcas. Lo único
disponible es lo disperso dentro de Freeman, anclado por versículo
específico (capa fina), no una fuente temática por época.

## 2. Gentil / exilio y post-exilio (Babilonia, Persia — ~586-400 a.C.)

**Sin fuente amplia dedicada.** Mismo caso que el anterior: ni Tucker (que
es específicamente sobre Roma del s. I) ni ningún otro módulo del
repositorio cubre las costumbres babilónicas o persas como fuente temática
independiente. Solo lo disperso en Freeman por versículo (relevante sobre
todo para Daniel, Ester, Esdras-Nehemías).

## 3. Gentil/romano tardío (Domiciano/Trajano — ~81-117 d.C.)

**Sin fuente amplia dedicada.** Tucker está anclado con evidencia textual
explícita a la época de Nerón (~54-68 d.C. — ver `costumbres-amplia-gentil.json`)
y no se extiende más allá. Esto deja sin cobertura el trasfondo romano
específico de Apocalipsis (culto imperial bajo Domiciano) y de las posturas
críticas de fecha tardía de 1-2 Pedro y las Pastorales, ya señaladas como
disputadas en `book-classification-nt.json`.

## 4. Cristiano / apostólico temprano (~30-90 d.C.)

**Sin fuente de costumbres contemporánea.** Es la ventana donde se escribió
la mayoría de las epístolas del NT, pero no hay ninguna fuente de
costumbres —distinta del propio texto bíblico— que describa la práctica
cristiana de este período específico. El material patrístico disponible
más cercano (Didaché, 1 Clemente) empieza recién en el entorno de 90-96
d.C. — ver `costumbres-amplia-cristiano-subapostolico.json`, que cubre la
época **subapostólica** (90-150 d.C.), explícitamente una etapa distinta y
posterior. Usar ese material como proxy del período apostólico temprano
sería una aproximación razonable pero no debe presentarse como si fuera
contemporáneo — la diferencia de décadas debe quedar visible si algún día
se usa así.

---

Estos 4 vacíos no bloquean el uso de lo que sí existe (Tucker para Roma
temprana, el bloque subapostólico, Freeman para el AT y el NT narrativo) —
solo delimitan honestamente dónde la capa amplia va a devolver "sin
resultado" hasta que haya una decisión futura de sumar contenido nuevo.
