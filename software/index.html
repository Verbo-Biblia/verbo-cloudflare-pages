ESTUDIO BÍBLICO · LINUX NATIVO

Verbo Desktop

Una aplicación de escritorio para leer la Biblia, estudiar el texto y preparar enseñanzas. Reúne módulos compatibles de e-Sword, MySword y Verbo en tu biblioteca.

  • Biblia, referencias cruzadas, Strong, diccionarios y comentarios.
  • Modo de preparación de enseñanzas y biblioteca de lectura.
  • Recursos históricos, mapas y notas cerca del pasaje.

PROYECCIÓN PARA IGLESIAS · LINUX

Lumbrera

El software de proyección de Verbo para iglesias. Prepara canciones y pasajes bíblicos, organiza el orden del culto y muestra el contenido en el proyector o televisor.

  • Cancionero local: crear, editar, importar y guardar letras.
  • Biblias seleccionables e importación compatible con e-Sword y MySword.
  • Proyección y controles desde una aplicación de escritorio Linux.
